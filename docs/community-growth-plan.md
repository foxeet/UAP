# 社区产品规划:让 UAP 网站「既能引爆，又让真实部分欲罢不能」

> 文档性质:增长 / 内容 / 游戏化 设计蓝图(v1)
> 关系:这是对 `docs/product-strategy.md`（可信度优先的定位与变现）的**延伸**，专攻它没深入的四块——讨论主题内容、病毒传播、游戏化、「真实又上瘾」引擎。
> 基调假设:**双轨并行**（外圈娱乐病毒层 + 内圈严肃可信层）；**中英双轨**市场。

---

## 0. 一句话核心机关:把「可信度工具」本身做成「游戏」

整个矛盾——「容易爆炸的社交/游戏属性」 vs 「真实部分让人欲罢不能」——的解法只有一个，**不要把娱乐层和可信层做成两套东西，而让同一组对象同时承担两件事**:

- **证据计量器（Evidence Meter）**：既是 Rio/San Marino 量表的可信度评级工具，**又是游戏分数**。
- **案卷（Case File）**：既是严肃的原始档案条目，**又是可收集、可追更的「卡牌」**。
- **段位（Ranks）**：晋级靠的是**证据推理质量**，不是「信得多深」——于是「玩得越深 = 越理性」。

> 这一条是后面所有设计的总纲:**让人上瘾的东西，恰好就是让人更严谨的东西。** 在一个 99% 是震惊体的赛道里，「克制 + 可复核」反而是最稀缺的爽点。

## 1. 总体架构:双轨漏斗

```
            ┌─────────────────────────────────────────┐
   引爆/拉新 │  外圈 · 奇观层  The Spectacle             │
            │  每日一案 · 梗图/案件卡 · ARG赛季 ·        │
            │  阵营对线 · 预测赛 · 一键分享物            │
            └───────────────┬─────────────────────────┘
                            │  转化钩子 = 证据计量器 / 案卷
            ┌───────────────▼─────────────────────────┐
   留存/信任 │  内圈 · 档案层  The Record                │
   /变现     │  原始解密文件 · 官方结论(resolved/未解) · │
            │  证据分级 · 未解案卷追更 · 科学追踪器 ·    │
            │  深度讨论 · 科幻×现实                      │
            └─────────────────────────────────────────┘
```

- **奇观层**目标:CTR、分享率、拉新。允许「好玩、有态度、有悬念」，但**所有断言都必须能下钻到档案层的证据**。
- **档案层**目标:停留时长、复访、订阅/付费。**视觉与规则上明显区别于奇观层**（不同配色/版式/标签），让用户清楚「我现在在严肃区还是娱乐区」。
- **两层之间的电梯**:任何一张梗图/案件卡，点进去都能看到原始文件 + 官方结论 + 证据评级 + 反方观点。**娱乐是入口，档案是落点。**

## 2. 三大讨论主题的内容设计

### 主题一 ·「如果这些档案有真的，人类应该如何面对」

做成常设栏目 **「接触推演 / Contact Scenarios」**，拆成 6 个可长期产出的维度。每个维度都挂真实学术/历史锚点，避免空谈:

| 维度 | 核心问题 | 真实锚点（可引用） | 旗舰选题示例 | 讨论引子 |
|---|---|---|---|---|
| 个人心理 | 冲击、意义感、存在主义焦虑 | 哥白尼式降格；宇宙级「文化冲击」研究 | 〈得知「我们不孤独」的第二天，你会怎么过〉 | 「如果明天官方确认，你最想问的一个问题是？」 |
| 社会文化 | 会大乱吗？信息真空才危险 | **《世界大战》广播恐慌其实被夸大**（后世研究证伪）；Brookings 报告「文明崩溃」是**以讹传讹的迷思** | 〈被误传 70 年的「外星恐慌」:真相是人们其实很冷静〉 | 「真正危险的不是外星人，是谣言。举一个你见过的例子。」 |
| 政治治理/安全 | 谁代表地球发言？军事误判风险 | IAA《行为准则》（不单方回应、经 UN 协调）；「Who Speaks for Earth」(SETI 经典命题) | 〈谁有权替全人类回话?〉 | 「该不该回应？由谁决定？投票 + 说理由。」 |
| 经济市场 | 产业、预测市场、信息冲击 | Kalshi 等预测市场已开盘；披露对国防/航天股的冲击 | 〈如果确认外星，哪些行业先地震〉 | 「你押多少概率，2030 前官方实锤？」 |
| 宗教哲学 | 各信仰如何回应；人类中心主义 | 梵蒂冈天文台公开表态过；费米悖论 | 〈五大信仰体系会怎么解释「他们」〉 | 「这会动摇你的世界观吗？为什么？」 |
| 科学范式 | 可证伪性、奥卡姆剃刀、外星 vs 未知自然 | 卡尔·萨根「非凡主张需非凡证据」；NASA 2023 报告核心结论 | 〈在喊「外星」之前，要先排除哪 12 种平凡解释〉 | 「给这条目击想 3 个无聊但更可能的解释。」 |

> 形式建议:每个维度配「**严肃版**长文 + **轻量版**投票/辩论卡」。轻量版进奇观层引流，长文留档案层留存。

### 主题二(a) ·「科学研究到了什么程度」——科学追踪器（Science Tracker）

常设栏目 **「前沿雷达 / The Frontier Radar」**:一张实时更新的「该追什么」清单，每条标注**当前状态**和**该用什么量表评级**。建议初始条目（上线前需逐条核实最新进展，标注日期）:

| 追踪条目 | 这是什么 | 现状（需核实） | 怎么评级 |
|---|---|---|---|
| AARO / NASA UAP 团队 | 美军/NASA 官方 UAP 研究 | 滚动出报告、影像；NASA 已设 UAP 研究主任 | resolved/unresolved 官方标签 |
| Galileo Project | Avi Loeb 的仪器化技术签名搜索 | 持续布设台站、发论文 | 同行评审 vs 媒体噪声 |
| SETI / Breakthrough Listen | 射电/光学技术签名搜索 | 长期无确认信号；持续扫描 | 信噪比、可重复性 |
| 系外行星生物标记 | JWST 测大气；**K2-18b 的 DMS 争议** | 「可能生物标记」被高调宣称又被同行质疑——**完美的「证据分级」教学案例** | 同行评审强度、是否可复现 |
| 星际天体 | 'Oumuamua、2I/Borisov、**3I/ATLAS** | 自然彗星/小行星 vs「人造」假说之争 | 奥卡姆剃刀打分 |
| 技术签名研究 | 戴森球、激光、工业污染信号 | 多为理论/搜寻阶段 | 理论成熟度 |

> 这个栏目的杀手锏:**教用户「区分科学里程碑和媒体震惊体」**——把每条新闻拖进证据计量器打分。K2-18b 的「发现生命迹象→其实证据不足」全过程，就是把流量话题转成可信度资产的最佳样板。

### 主题二(b) ·「电影、书籍、科幻小说」——科幻 × 现实对照（Fiction vs Evidence）

常设栏目 **「虚构对照组 / The Fiction Lens」**:精选 canon，每部配「它塑造了什么期待 / 现实科学怎么说」。

- **片单/书单卡片**:《降临 Arrival》（语言学接触、IAA 思路）、《三体》（黑暗森林 vs METI 辩论）、《超时空接触 Contact》（SETI、卡尔·萨根）、《天外来客》、《E.T.》《第三类接触》（流行文化如何塑造「小灰人」刻板印象）。
- **可复用形式**:①「虚构 vs 证据」逐条对照；②观影/读书会（直播 + 讨论）；③「科幻预言打分」（哪些被现实验证、哪些纯幻想）。
- **作用**:文化层是**最安全的破圈入口**（无合规风险、人人能聊），把泛科幻受众导流进硬核档案层。

## 3. 病毒传播机制（奇观层）

**核心原则:每个可分享物都自带「可信下钻」，让转发不掉价。**

1. **每日一案 · Daily Unidentified**（Wordle 式习惯钩子 ⭐最高优先级）
   - 每天一个真实未解案件，给 3 条线索，让用户**先猜「气球/鸟/飞机/传感器/真·未解」再揭晓官方结论**。
   - 结果生成**无剧透的分享格**（类似 Wordle 的彩色方块）:「我今天 3 猜命中 AARO 结论 🟩🟩⬛ 你呢？」→ 自带病毒环 + 每日复访。
2. **案件卡 · Case Card**:任意案件一键生成精美长图（缩略图 + 证据评级 + 官方结论 + 二维码回链），适配小红书/X 转发。
3. **立场计分卡**:「你是 73% 怀疑论者」式人格化结果卡，社交货币。
4. **「带个怀疑论朋友」裂变**:邀请机制做成「拉一个朋友来对线/合作解一案」，双向奖励解锁。利用「想说服对方」的社交动力。
5. **每周必出模板（memetic engine）**:①前/后逐帧打假短视频；②「这到底是不是 UAP?你来判」投票；③「Are you seeing this?」式悬念剪辑（用真实案件，结尾给官方结论，不烂尾）。
6. **平台分发**:
   - **全球**:X / YouTube / TikTok / **Reddit（种子社区）** / **Discord（核心据点）**。
   - **中国**:B 站（深度解读）/ 小红书（案件卡）/ 抖音（每日一案短视频）/ 公众号（档案长文）。
   - **冷启动种子**:先在 Reddit r/UFOs、Discord 养 500-1000 真·核心用户，再向大平台外溢。

## 4. 游戏化系统

| 机制 | 玩法 | 同时服务 | 防滥用/防伪科学 |
|---|---|---|---|
| **段位身份** 解密员→分析师→档案官→首席 | 晋级靠**证据推理质量**（被采纳的评级、优质反驳），不靠发帖量或「信得深」 | 留存 + 把激励对齐到「理性」 | 评级需引用来源；同行评审打分 |
| **证据计量器（评审游戏）** | 用户对案件按 Rio/San Marino 打分，形成社区共识曲线，与专家评级对比 | 传播（争议）+ 可信（量表） | 公开方法学、可复核、显示分歧 |
| **公民侦探任务** | 协作做逐帧、地理定位、气象/航迹比对（仿 Zooniverse/Foldit/GeoGuessr） | 留存 + 产出真实价值 | 多人交叉验证、禁止人肉真人 |
| **ARG 赛季 / 元谜题** | 一条贯穿赛季的解谜叙事，**关卡用真实未解档案**（不编造假证据） | 引爆 + 深度黏性 | 明确标注「游戏叙事 vs 真实档案」分层 |
| **预测赛 · Forecast League** | 预测「这段会被判 resolved/未解」「官方 X 年前是否确认」 | 传播（赔率天生爱传）+ 复访 | **只用积分/信息，不做真金赌盘**；中国侧进一步淡化 |
| **阵营对线（良性）** | 相信者 / 怀疑者 / 「拿数据来」三方辩论赛、红蓝队打假 | 传播（对线最病毒） | 评分奖励**论证质量**而非立场；禁止人身攻击 |
| **可收集案卷卡牌** | 案件做成可收集卡，稀有度=证据强度 | 收集欲 + 复访 | 卡面=真实信息，不夸大 |

> 关键拿捏:**把「怀疑」做成高地位玩法**。在多数 UFO 社区里「信得多」才有地位，这正是它们滑向阴谋论的结构性原因。我们反过来——**段位最高的是最会证伪、最会打分的人**，从机制上免疫 QAnon 化。

## 5. 「真实又上瘾」引擎(档案层)

把事实性内容做出追剧般的黏性，且**诚实、不造钩子**:

1. **季更追更**:每隔几周的官方「解密批次」做成「新一季」，用户可「订阅追更」某个案件/主题。批次发布日 = 平台的「番剧更新日」。
2. **开放案卷（Open Case）= 合法的悬念**:「unresolved」这个**事实状态本身**就是天然 cliffhanger（蔡格尼克效应/未闭合循环）。UI 上把「未解」做成「待续」，但**绝不假装有结论**——诚实地留钩子。
3. **证据计量器实时跳动**:有新证据/新分析时评级变动，推送「你关注的案件评级变了」。把「证据更新」做成多巴胺事件。
4. **节制的通知**:只在「你关注的案件有实质更新」时推；**明确拒绝**无限下拉的信息流诱导、虚假红点、人造稀缺倒计时等 dark patterns。
5. **惊奇 vs 怀疑的双引擎**:内容同时给「想相信的浪漫」（叙事运输）和「要求证据的冷静」（批判工具）——这种张力本身是核心情绪爽点。
6. **护栏即卖点**:公开来源、可纠错、不夸大——做成「在这里我不会被忽悠」的安心感。**我们主动声明拒绝使用的成瘾设计**（见 §7），把克制变成信任资产。

> **用户一周旅程示例**:周一玩「每日一案」分享战绩 → 周三收到「关注的休伦湖案件出了新红外画面，评级从『可能气球』→『未解』」推送，回访读档案 + 投票 → 周五参加「相信者 vs 怀疑者」周赛拿积分升段 → 周日 ARG 赛季更新一关，需用真实档案线索解谜 → 顺手把案件卡发小红书拉来一个朋友。

## 6. 先例与教训（可直接借鉴 / 必须规避）

| 类别 | 代表案例 | 可借鉴 | 必须规避 |
|---|---|---|---|
| 每日轻游戏 | **Wordle / GeoGuessr / Connections** | 每日一次 + 无剧透分享格 = 病毒留存神器 | 别做成肝度任务 |
| 公民科学 | **Zooniverse / Galaxy Zoo / Foldit** | 微任务 + 真实贡献 + 多人校验 | 没有质量控制就会被垃圾淹没 |
| ARG 解谜 | **Cicada 3301 / I Love Bees** | 分布式协作解谜的巨大黏性 | 谜题失控/无人维护会烂尾 |
| UAP 社区 | **Reddit r/UFOs(数百万)、Enigma Labs、Galileo、Sol Foundation、The Debrief** | 各占「上报/研究/学术/媒体」生态位 → 我们占空白的「响应/素养/决策」 | 可信度一旦崩，社区整体掉价 |
| 失败/危险 | **Reddit 误指波士顿爆炸案嫌犯;QAnon 式集体解谜** | —— | **绝不**搞人肉/指认真人;**绝不**用「自己做研究」话术滑向 apophenia(模式幻觉)/阴谋论 |

> **5 条最关键启示**:① 每日 + 一键分享 = 最强病毒留存;② 把「贡献」做成真实有价值的微任务;③ 让「怀疑/证伪」成为高地位玩法,结构性免疫阴谋论;④ 可信度是易碎品,一次崩塌全盘皆输;⑤ 永远禁止指认真实个人。

## 7. 对抗性自检:红线与护栏

**3 条绝不碰的红线:**
1. **绝不指认/人肉真实个人**（防波士顿爆炸案式误伤）。
2. **绝不用「政府隐瞒/末日预言/封建迷信」框架**做主线（中国侧封号红线 + 全球侧可信度红线）；预测玩法**不做真金赌盘**。
3. **绝不让 AI 或用户伪造「证据」**——ARG 叙事与真实档案永远视觉/标签分层；外圈梗图必须可下钻到真档案。

**3 个最该加固的护栏:**
1. **激励对齐**:段位/积分奖励**证据质量与证伪能力**，不奖励「信得深」或纯流量——从机制上把社区拉向理性。
2. **脆弱人群保护**:对妄想/焦虑倾向内容做降权;提供「这只是情景推演」的清晰标注;不制造恐慌或 FOMO 逼单。
3. **规模化治理**:版主体系 + AI 辅助审核(识别人肉、阴谋论滑坡、伪造素材) + 社区初始文化刻意塑造(种子期就立「拿证据说话」的规范)。

## 8. 度量、冷启动与路线图

**北极星指标**:可信度（被权威媒体/教育引用次数）。**双轨健康度**:用「病毒系数 K / 分享率」衡量传播，用「证据评级参与率 / 纠错时效 / 优质讨论占比」衡量可信——两者都要看,防止为流量牺牲可信。

**冷启动 90 天:**
- 0–30 天:上线**「每日一案」+ 50 个精编案卷 + 证据计量器**;在 Reddit/Discord 养 500 核心用户,立社区规范。
- 30–60 天:开**预测赛 + 阵营周赛**;每周固定产出梗图模板;接 3-5 个科普 KOL。
- 60–90 天:上**公民侦探任务 + ARG 第一赛季**;开免费 newsletter + 付费墙占位;数据复盘砍掉留不住人的玩法。

**6–12 个月**:科幻×现实读书会、播客/音频、线下观星、教育版课包、AI 个性化追踪;引入科学顾问委员会;跑通中英双轨变现。

**上线前必答的 8 个问题**:① 双轨的视觉/规则边界具体怎么划?② 段位激励到底奖励什么(防滑向信仰打分)?③ ARG 真档案与游戏叙事如何标注分层?④ 预测玩法中/全球两版合规方案?⑤ 规模化审核与防人肉的具体流程?⑥ 病毒机制如何不破坏付费/B2B 体验?⑦ 数据隐私(上报含位置/媒体)如何满足 GDPR/PIPL?⑧ 哪些指标触发「砍掉某玩法」?
