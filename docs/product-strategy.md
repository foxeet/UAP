# 产品战略：「假如 2027 遇到外星人，地球人怎么办」科学预案网站

> 文档性质：产品/商业蓝图（v1）
> 整理日期：2026-06-14
> 一句话：把全网最不严肃的话题，做成**最严肃、最可信、最可执行**的那一个。

---

## 0. 重要的负责任框定（先立规矩，再谈生意）

1. **「2027」是情景推演，不是预言。** 这个日期来自 2023 年 2 月前 CIA 人员 John Ramirez 在播客上的说法，后被遥视(remote viewing)、昴宿星(Pleiadian)等圈子放大，**属于传闻/猜测，不是科学结论**。批评者把它类比 Y2K、2012 玛雅末日。我们**用它做钩子吸引流量，但永远明确标注它是传闻**——这恰恰是产品的卖点（见「谣言 vs 证据」评级）。
2. **科学优先，不贩卖恐惧，不搞伪科学，不做欺诈式变现。** 不卖「外星避难险」「防绑架护符」这类东西。我们卖的是**认知、工具、社区**。
3. **诚实区分三件事**：①已证实的事实（UAP 解密、SETI 协议）；②科学界的严肃讨论（后探测协议、METI 辩论）；③民间传闻（2027、阴谋论）。三者在站内**视觉上永远分层、永不混淆**。

> 这一节不是免责声明，而是**护城河**：在一个 99% 是 clickbait 和割韭菜的赛道里，「可信」本身就是最稀缺、最值钱的资产。

---

## 1. 定位与命名

**一句话定位**：地球的「接触响应」科普与预案平台——用真实科学，回答「如果真遇上了，我们（个人/社会/人类）该怎么办」。

**候选站名（中英）**：
| 中文 | 英文 | 气质 |
|---|---|---|
| 回声 / 回声协议 | **Echo / The Echo Protocol** | 中性、科学、克制；"回应来自星空的回声" |
| 第一接触手册 | **First Contact Handbook / FirstContact.earth** | 直给、工具感、SEO 友好 |
| 谁为地球发言 | **Who Speaks for Earth** | 借用 SETI 经典命题，思想深度，媒体感 |

推荐主品牌 **Echo（回声协议）** + 工具子品牌 **First Contact Handbook**。

## 2. 为什么是现在（市场机会）

- **官方供给侧爆发**：2026 年美国 PURSUE 三批解密 + AARO 影像库 + NASA 2023 独立研究报告，UAP 从「边缘话题」变成「政府盖章的公开议题」。话题有了**官方背书的合法性**。
- **需求侧高热**：盖洛普等民调显示相当比例公众相信 UFO/外星存在；Kalshi 等**预测市场**甚至开出「美国是否会确认外星存在」的盘口——说明存在愿意「下注」的高意向人群。
- **科学侧成熟**：SETI 后探测协议正在 2022–2025 更新，St Andrews 成立**后探测中心(Post-Detection Hub)**，「人类该如何应对」第一次有了**严肃的学术脚手架**可引用。
- **竞争侧留白**：现有玩家各占一角，但**「该怎么办」这一层无人可信地占据**（见 §4）。

> 结论：话题热度、官方合法性、科学严肃性、竞争空白，四者**罕见地同时具备**。窗口期就是 2026–2028。

## 3. 四种产品形态对比（先发散，再收敛）

| 形态 | 核心资产 | 公信力 | 需求/流量 | 变现潜力 | 可持续 | 壁垒 | 伦理风险 |
|---|---|---|---|---|---|---|---|
| A 科学解释/媒体公信力 | 内容+权威 | ★★★★★ | ★★★★ | ★★★ | ★★★★ | 中(品牌) | 低 |
| B 公民科学+社区预案 | 社区+数据 | ★★★★ | ★★★ | ★★★ | ★★★★★ | 高(数据网络效应) | 中(数据隐私) |
| C 接触响应协议工具/情景模拟 SaaS | 产品+工具 | ★★★★ | ★★★ | ★★★★ | ★★★★ | 中高(产品) | 中(过度承诺) |
| D 媒体品牌/IP | 品牌+内容 IP | ★★★ | ★★★★★ | ★★★★ | ★★★ | 低→中 | 中(娱乐化滑坡) |

**推荐：以 A（公信力）为主干 + C（协议工具）为差异化招牌 + D（媒体）为流量引擎 + B（社区/数据）为长期护城河。** 顺序很重要：**先用 D 拉流量、用 A 建信任，再用 C/B 沉淀与变现。**

理由：A 提供「为什么信我」，C 提供「我能为你做什么（别人没有的）」，D 解决冷启动获客，B 提供别人抄不走的网络效应。单押任何一个都不稳：纯 A 难变现、纯 D 易娱乐化掉价、纯 B 像 Enigma 一样卡在「免费且不知如何收费」、纯 C 容易过度承诺变成卖焦虑。

## 4. 竞争差异化：我们占哪个词

- **Enigma Labs** = 「**上报**目击」（50k+ 报告、VC 背书，但**免费/无广告、变现未验证**）。
- **Galileo Project / Avi Loeb** = 「**研究**」（哈佛、慈善资助、提议十亿美元「UAP 曼哈顿计划」）。
- **MUFON / The Debrief / Coast to Coast** = 「**社群/媒体/爆料**」。
- **留白 → 我们占「响应 / 决策 / 素养」**：遇到了**该怎么办**、信息真假**怎么判断**、社会**该如何治理**。这是动作层和认知层，**目前无人可信地占据**。

> 一句话差异：别人帮你**看见**和**研究**不明现象；我们帮你**理解**它、**判断**它、并知道**该怎么做**。

## 5. 目标人群分层

1. **科学好奇者 / 泛科普受众（最大盘）**——要「靠谱的解释」，反感民科和阴谋论。→ 内容+会员。
2. **理性爱好者 / 硬核 UAP 圈**——要数据、要量表、要一手来源。→ 工具+数据+社区。
3. **教育者（老师/科普馆/天文社团）**——要现成的课程、课件、课堂活动。→ B2B/edu 授权（高客单）。
4. **媒体/记者/品牌**——要可引用的权威信源与数据。→ 数据/内容授权、赞助。
5. **「预案/preparedness」人群**——要「真遇上我该做什么」的清单。→ 工具+周边（**审慎，不卖恐惧**）。
6. **下注型高意向人群**——关注预测市场、爱「赔率/概率」。→ 「证据评级/赔率」内容（不开赌盘，只做信息）。

## 6. 内容支柱与招牌功能

### 内容支柱（建立信任）
- **解密追踪**：把 PURSUE/AARO/NASA 等官方资料做成中文权威解读（已有基础，见仓库 README）。
- **科学脚手架**：SETI 后探测协议、Rio/San Marino 量表、METI 辩论、「谁为地球发言」治理问题——讲成人人能懂的科普。
- **谣言体检**：对「2027」等热门传闻做溯源与证据评级。

### 招牌功能（别人没有的差异化）

1. **「接触响应协议」交互工具（First Contact Protocol）** ⭐ 核心
   - 扎根**真实框架**：IAA《行为准则》（不单方回应、经联合国协调）、Rio Scale 2.0、San Marino Scale、后探测中心方法论。
   - 分层输出预案：**个人/家庭 → 学校/社区 → 机构/政府 → 全人类**，每层「如果发生 X，权威建议的做法是 Y，依据是 Z（一手来源）」。
   - 强调**核实优先、不恐慌、不单边行动、信息素养**——把科学共识翻译成可操作清单。

2. **「谣言 vs 证据」评级系统（Evidence Meter）** ⭐
   - 借用 **Rio Scale** 思路，给每条热门主张打分：可信度 × 影响力 →0-10 分 + 证据等级（一手政府文件 / 同行评审 / 媒体转述 / 匿名爆料 / 纯传闻）。
   - 「2027」这类直接标为「传闻级，证据=0」，并给出溯源。**这是把流量话题转成公信力资产的关键机关。**

3. **情景模拟器（Scenario Simulator）**
   - 交互式「假如……会怎样」：检测到信号 / 近距离目击 / 官方确认 / 物理接触……分支推演社会、经济、心理反应，每个结论都挂科学/历史依据（如恐慌其实少见、信息真空才危险）。

4. **公民观测 + 地图（长期，B 形态）**
   - 标准化上报 + 地图聚合 + 自动用量表评级；与「响应」层打通，形成数据护城河。

## 7. 公信力与科学治理机制（护城河的核心）

- **科学顾问委员会**：邀请天文/SETI/天体生物/科学传播/法律治理学者挂名背书（哪怕轻量）。对标 Galileo 的学术气质。
- **编辑规范公开**：来源分级、更正政策、利益披露——像新闻机构一样运营。
- **一手来源优先**：凡结论必挂 `.gov/.edu/`同行评审链接；二手转述明确标注。
- **量表标准化**：所有「可信度」判断走 Rio/San Marino 公开方法，**可复核、不拍脑袋**。
- **伦理章程**（见 §12）：反恐慌、反伪科学、反欺诈，写进产品 DNA 并公示。

## 8. 变现栈（伦理变现，分阶段）

> 原则：**先建信任与流量，再变现；优先「已被验证有付费意愿」的模式（内容/教育），审慎对待「未验证」的模式（预案消费品）。**

**阶段一（0–6 月，验证）**
- **免费 newsletter + 科普短视频**：不直接赚钱，是漏斗顶端（获客）。
- **付费会员/订阅**（Ghost/Substack/小报童）：深度解读、完整协议工具、无干扰阅读。基准：小众 newsletter 免费→付费转化 ~3–8%，ARPU ~$5–8/月。
- **打赏/众筹**（知识星球/爱发电/Buy Me a Coffee）：低门槛启动。

**阶段二（6–18 月，放大）**
- **在线课程/工作坊**：「如何辨别 UAP 信息真假」「学校天文+批判性思维课包」——**教育付费意愿强、客单高**。
- **B2B/edu 授权**：课件、量表 API、数据面板授权给学校/科普馆/媒体。高 ACV、低边际成本。
- **品牌赞助/内容合作**：科学/科技/天文品牌赞助 newsletter 与播客（**只接与公信力相符的**）。

**阶段三（18 月+，护城河）**
- **数据产品**：标准化目击数据集授权给研究者/媒体/保险/无人机安防等 B 端。
- **IP/周边**：高质量设计周边、书、纪录片/播客 IP（**审美驱动，不是恐惧驱动**）。
- **会员制社区/线下活动**：观星营、沙龙、年度大会。

> **诚实提醒**：这是**慢生意（内容+社区复利）**，不是爆发式 SaaS。第一年目标是「可信品牌 + 几千付费会员」，不是「百万营收」。把它当媒体+教育公司来建模，而非消费 App。

**粗略单元经济（示意，非承诺）**：月访客 5 万 → 免费订阅 5,000 → 付费 5%＝250 人 × ¥40/月 ≈ ¥1 万/月起步；叠加 1–2 个 edu/B2B 授权合同（单合同年 ¥5–20 万）才是利润主力。**真正的杠杆在 B2B/edu，不在 C 端打赏。**

## 9. 技术架构建议

- **前端/站点**：Next.js (App Router) + TypeScript + Tailwind；内容走 MDX/Headless CMS（Sanity/Contentful 或 Ghost）。SEO 与性能优先（话题靠搜索/社交获客）。
- **交互工具**：协议工具/评级/模拟器用 React 组件 + 轻状态机；规则与依据存为结构化 JSON（可审计、可引用）。
- **数据层**：Postgres（Supabase）存目击上报/评级；PostGIS + MapLibre 做地图。
- **AI 用法（克制、可信）**：
  - 用 LLM 做**资料结构化、多语翻译、初稿摘要、相似目击聚类**；
  - **绝不**让 AI「编」结论或证据——所有对外事实必须挂一手来源；AI 产出走「人审 + 来源校验」。
  - 选用最新 Claude 模型（如 Claude Opus 4.8 / Sonnet）做内容流水线。
- **支付**：全球用 Stripe（订阅）；中国用微信支付/知识星球/小报童（见 §10）。
- **抓取/数据管道**：复用本仓库已写的 `uap_scraper`（纯标准库、egress 感知），主机放行后即可自动拉取官方资料。

## 10. 中国 vs 全球：市场与合规本地化（关键风险）

**核心判断：把「全球英文市场」作为主要变现地，把「中国」作为内容/流量与科普品牌地——而非主要收钱地。**

- **中国内容合规红线**：「UFO/外星」作为**科普/娱乐**可行；但「**末日/灾难预言**」「**2027 大事件**」「**政府隐瞒**」等框架易被判定为**谣言/封建迷信/扰乱社会秩序**，账号有被限流封禁风险。
  - 对策：在中国渠道**只做「科普 + 思想实验 + 批判性思维」**人设；**淡化「2027 预言」**，强调「如何不被谣言带节奏」；不碰阴谋论、不影射官方。
- **中国变现渠道**：知识星球/小报童（订阅）、视频号/B 站/小红书（流量与广告）、微信小程序（工具）。**不能用 Patreon/Stripe**。
- **全球渠道**：英文站 + Substack/Ghost + Stripe + YouTube/X；监管宽松、付费基建成熟、ARPU 更高。**协议工具、数据授权、课程主要面向全球英文 B/C 端。**
- **数据合规**：用户上报含位置/媒体 → 适配 GDPR / 中国《个人信息保护法》：最小化采集、匿名化、明确同意、可删除。

## 11. 可持续性与护城河

1. **公信力品牌**（最难抄）——靠时间、规范、顾问、纠错记录累积。
2. **结构化知识库 + 量表方法论**——可引用、可被媒体/教育反复使用。
3. **公民观测数据网络效应**（B 形态）——越多人用越有价值。
4. **多元收入**——内容/教育/B2B/数据/IP 分散风险，不依赖单一渠道或平台。
5. **跨语言**——中英双语内容资产，覆盖两个大市场。

## 12. 伦理与合规章程（公示在站内）

- **不制造恐慌**：所有「该怎么办」以「核实优先、保持冷静、不要单边行动」为基调。
- **不伪科学**：不主张未经证据支持的断言；传闻明确标级。
- **不欺诈变现**：不卖虚假功效产品/服务，不用「倒计时焦虑」逼单。
- **来源透明 + 可纠错**：公开来源与更正记录。
- **隐私优先**：上报数据最小化、匿名化、可删除。
- **政治中立**：不影射、不阴谋论、不针对特定政府/族群。

## 13. 对抗性自检（把质疑写在明处）

| 质疑 | 回应 / 对策 |
|---|---|
| **会不会滑向伪科学/恐慌营销？** | 用「证据分级 + 一手来源 + 伦理章程」做硬约束；传闻与事实视觉分层；KPI 里加「纠错及时性」。 |
| **变现会不会变割韭菜/违法？** | 砍掉一切「功效型」消费品；主攻内容/教育/B2B（已验证付费意愿）；广告/赞助做合规披露；支付走正规渠道。 |
| **人们真会为「外星预案」付费吗？需求是否被高估？** | **承认存疑**。因此第一年**不赌 C 端「预案消费」**，而押**已被证明能收钱的「深度内容+教育+B2B 授权」**；用免费工具引流、用付费内容/课程变现。 |
| **相对 Enigma/Galileo 有真壁垒吗？** | 不与其正面竞争（上报/研究），占「响应/素养/决策」空白层；壁垒是公信力品牌+方法论+双语+多元收入，而非单一数据。 |
| **中国监管风险？** | 内容人设「科普/思辨」、淡化预言、不碰阴谋论；变现主战场放全球英文；中国侧以品牌/流量为主。 |
| **「2027」过去后话题降温怎么办？** | 钩子可替换（话题会持续有新「日期/事件」）；真正资产是**长青的科学素养内容 + 工具 + 社区**，不绑死单一日期。 |

## 14. MVP 与路线图

**MVP（4–6 周，可由本仓库起步）**
1. 内容站（Next.js）+ 3–5 篇旗舰文章（复用现有 UAP 中文解读）。
2. **「谣言 vs 证据」评级**首发：以「2027 传闻」为样板案例。
3. **「接触响应协议」工具 v0**：个人/家庭层 + 科学依据链接。
4. 免费 newsletter 订阅 + 一个付费墙占位。
5. 复用 `uap_scraper` 自动更新官方资料源（放行主机后）。

**90 天**：稳定更新节奏（每周）+ 协议工具补齐学校/机构层 + 上线付费会员 + 起量社交渠道（B 站/小红书/X/YouTube）。
**6–12 月**：上线情景模拟器 + 公民上报地图（B）+ 第一门课程/第一个 edu 授权 + 引入顾问委员会。

**北极星指标**：可信度（被权威媒体/教育引用次数）。
**辅助 KPI**：周更新率、免费订阅数、免费→付费转化率、付费会员留存、工具完成率、纠错时效、B2B 合同数。

**财务模型（保守，示意）**：
- 6 月：~5k 免费订阅，~200–400 付费，月收 ¥1–2 万（内容会员为主）。
- 12 月：~2–3 万免费订阅，~1k 付费 + 1–3 个 edu/B2B 合同，月收 ¥5–15 万（B2B/课程成为主力）。
- 把它当**复利型内容+教育公司**看：18–24 月达到「养活小团队」级别是现实目标。
